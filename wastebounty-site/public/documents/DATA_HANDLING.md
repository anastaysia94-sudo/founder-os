# WASTEBounty Data-Handling Rules

1. **Minimum necessary data only.** Request only records needed to analyze a defined cost category.
2. **No passwords or secret keys.** Initial audits should be file/export based.
3. **No unrelated personal/customer data.** Redact it before sharing when practical.
4. **Read-only first.** Analysis does not require production write access.
5. **Client controls vendor actions.** No cancellation, downgrade, negotiation, or purchase without explicit authorization.
6. **Evidence traceability.** Each saving must point back to the supporting invoice, contract, usage export, or written vendor confirmation.
7. **Separate estimates from facts.** Estimated savings remain estimates until documented.
8. **Retention rule.** Agree with the client how long working files are retained and delete/return them when the engagement ends, subject to legal/business record requirements.
9. **Access rule.** Only people needed for the pilot should access supplied data.
10. **Incident rule.** If confidential data is sent accidentally, stop using it, notify the client, and agree on deletion/replacement.
