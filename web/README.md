# FDOS Standalone Web

Non-WordPress product track for Founder Dynasty OS. It is intentionally separated from the legacy WordPress plugin so feature development can continue without WordPress.

## Implemented in this track
- responsive Founder Command Center shell
- founder intake: website, Facebook/business URL, business idea
- E1–E8 Evidence Vault
- transparent opportunity ranking
- Value Sprint panel
- explicit truth boundary: this preview does not pretend submitted URLs were fetched

## Run
`npm install` then `npm run dev`.
