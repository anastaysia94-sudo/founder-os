# Interview Frameworks

## Tell me about yourself
Target role -> strongest verified evidence -> current proof project -> why this role.

## Angry customer
Acknowledge -> clarify -> verify -> offer the allowed next step -> document or escalate.

## I do not know the answer
State what you know -> check approved sources -> escalate when needed -> set an update expectation.

## Multiple priorities
Handle safety/account/payment blockers first, then deadlines or service commitments, then quick wins.

## Behavioral questions
Use a real example. Do not present a fictional practice scenario as employment history.
