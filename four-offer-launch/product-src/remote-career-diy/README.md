# Remote Career Command Center DIY

A reusable, evidence-first system for organizing a remote job search.

Included:
- TARGET_ROLE_WORKSHEET.md
- APPLICATION_TRACKER.csv
- STAR_STORY_BUILDER.md
- WEEKLY_REVIEW.md
- INTERVIEW_FRAMEWORKS.md

Use only claims you can verify. Replace placeholders with your own facts. This pack does not guarantee interviews, offers, or employment.
