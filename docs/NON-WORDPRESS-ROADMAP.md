# FDOS Non-WordPress Product Roadmap

WordPress is a supported adapter, not the definition of Founder Dynasty OS.

## Architecture
1. Evidence Core — E1–E8, confidence, sources, limitations, evidence history.
2. Decision Core — Value Leaks, opportunity ranking, hypotheses, Value Sprints, KPIs, KEEP/REVISE/REVERT.
3. Founder Workspace — projects, goals, Evidence Vault, decisions, experiments, next-best action.
4. Adapters — website capture, Shopify, analytics/imports, optional WordPress.
5. Interfaces — standalone web/PWA, API, founder console, future mobile clients.

## Feature sequence
- **N001 Portable FDOS data contract — BUILT.** `core/schema/fdos.schema.json`.
- **N002 Standalone Decision Lab — BUILT.** `standalone/` runs without WordPress or a server.
- **N003 Import/export compatibility — NEXT.** Validation, migrations, conflicts, portable bundles.
- **N004 Multi-project portfolio intelligence.** Compare project health/opportunities and resource allocation.
- **N005 Dynasty Vault.** Decision history with evidence-at-decision-time, alternatives, confidence and results.
- **N006 KPI measurement engine.** Metric definitions, baselines, observation windows, guardrails and sufficiency.
- **N007 Evidence ingestion adapters.** CSV/JSON, Shopify/analytics exports, surveys/interviews, manual verified facts.
- **N008 AI Council contract.** Recommendation + evidence + missing evidence + assumptions + counterargument + reversible test + KPI.
- **N009 Guided founder onboarding.** Website/business idea/company → first evidence map → first Value Sprint.
- **N010 Accounts/sync API.** Portable auth/workspace sync independent of WordPress with RBAC/audit/privacy controls.

## Truth boundary
A local standalone interface working is an internal implementation fact, not evidence of production deployment, customer value, revenue, product-market fit or business impact.
